# EntityCount

A simple Minecraft mod that shows how many entities are around you in real-time.

## Count Entities In Your Loaded Chunks (Client Side)

![pins, itemEntities](https://cdn.modrinth.com/data/cached_images/b6549d51450007f9e00524cdf836cfd9e20e4ee1.png)

## What does this mod do?

EntityCount displays a list on your screen showing how many of each type of entity (mobs, animals, items, etc.) are currently loaded around you.

**All languages supported** (29+ languages including English, Chinese, Japanese, Korean, Russian, and more!)

## Features

### 📌 Pinned List
- **Pin important entities** to the top of the display
- Pinned entities stay visible **even when count is 0**
- Perfect for tracking specific mobs or items you care about

### 📦 Item Display Expansion
- **Toggle detailed item display** for dropped items
- Shows specific item names (e.g., "Item.Diamond", "Item.Iron Ingot")
- Helps track exactly what items are on the ground

### 🎨 Full Customization
Access settings through **Mod Menu** → **EntityCount** → **Configure**

Or press **KeyBinding "O"** (default, customizable) if **Mod Menu** is not installed

#### Display Settings
- **Turn on/off** the entity count display
- **Show all entities** or **only living ones** (animals, mobs)
- **Change colors** - text color, background color, and transparency
- **Adjust text size** - scale the display to your preference
- **Drag to move** - click and drag the display box to reposition

#### Filtering Options
- **Whitelist mode** - Only show specific entities you choose
- **Blacklist mode** - Hide entities you don't want to see
- **Pinned list** - Keep important entities always visible at the top
- **Threshold filter** - Only show entities with count ≥ threshold value
- **Type limit** - Limit the maximum number of entity types displayed

#### Advanced Options
- **Custom position** - Fine-tune X/Y coordinates (0.0 - 1.0)
- **Expand item display** - Show detailed names for dropped items

## Installation

### Required Dependencies
- **[Fabric API](https://modrinth.com/mod/fabric-api)** - Required for all Fabric mods
- **[Cloth Config](https://modrinth.com/mod/cloth-config)** - Required for configuration screen

### Optional Dependencies
- **[Mod Menu](https://modrinth.com/mod/modmenu)** - Recommended for easy access to config screen
  - If not installed, you can use the **"O" key** to open settings

## Supported Versions
- **Currently maintaining**: 
  - `1.21.6 - 1.21.8` (Fabric)
  - `1.21.9 - 1.21.10` (Fabric)

## Usage Tips

1. **Pin important entities**: Add entity names to the pinned list to always see them at the top
2. **Track dropped items**: Enable "Expand Item Display" to see exactly what items are on the ground
3. **Reduce clutter**: Use threshold or type limit to show only the most common entities
4. **Quick toggle**: Press "O" to open settings anytime (customizable keybinding)
